
# LeafLens AI

Explainable plant disease detection using lightweight deep learning.

## Overview

LeafLens AI is a machine learning project that classifies plant leaf
images into disease categories using transfer learning.

The project explores the balance between classification performance,
computational efficiency, and model explainability.

## Planned Features

- Plant disease classification from leaf images
- Transfer learning with MobileNetV2
- Comparison with EfficientNetB0
- Grad-CAM visual explanations
- Evaluation using accuracy, precision, recall, and F1-score
- Inference time and model size comparison
- Streamlit web interface

## Technology Stack

- Python
- TensorFlow / Keras
- Streamlit
- NumPy and Pandas
- Matplotlib
- Scikit-learn

## Dataset

PlantVillage public dataset.

## Research Objective

To evaluate whether lightweight deep learning models can provide
effective and interpretable plant disease classification while
reducing computational requirements.
